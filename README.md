# Atomic Book Club Worker

This is the upload-without-copy-paste version.

Open a terminal in this folder and run:

```text
npx wrangler login
npx wrangler deploy
npx wrangler secret put RESEND_API_KEY
```

Paste your Resend API key only when Wrangler asks for it.

After this, Cloudflare will give you a `workers.dev` URL for testing.
